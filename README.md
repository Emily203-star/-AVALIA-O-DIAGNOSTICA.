# Atividade Diagnóstica - Desenvolvimento para Dispositivos Móveis

Resolução das seis questões propostas na atividade, utilizando JavaScript.

## Estrutura

- `questao01.js`: calculadora de compra;
- `questao02.js`: situação acadêmica;
- `questao03.js`: simulação do consumo de bateria;
- `questao04.js`: controle de consumo de internet;
- `questao05.js`: cadastro de aplicativo;
- `questao06.js`: análise de avaliações.


## Como executar

É necessário possuir o Node.js instalado. Abra o terminal na pasta do projeto e execute a questão desejada:

```bash
node questao01.js
```

O programa solicitará os dados necessários. Para executar outra questão, basta trocar o nome do arquivo no comando.
Quando houver alternativas fixas, o programa exibirá um menu numérico, como `1 - Pix`, `2 - Cartão` e `3 - Dinheiro`.
Campos obrigatórios não aceitam respostas vazias, e a quantidade comprada deve ser um número inteiro.

Exemplo:

```bash
node questao06.js
```
